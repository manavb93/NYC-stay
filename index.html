About the project

StayWise NYC is a machine learning application built on the NYC Airbnb Open Data dataset. It solves a multiclass classification problem: given a listing's location, price, availability and review activity, which of three room types is it?

  • Multiclass classification across three room types
  • Python and Scikit-learn for modelling
  • Data preprocessing and feature engineering
  • Machine learning pipelines with ColumnTransformer
  • Model deployment with FastAPI
  1. User InputTen listing features from the form
  2. Data ValidationPydantic checks types and ranges
  3. ML PipelineImputing, scaling, encoding, classifier
  4. Predicted Room TypeReturned as JSON to this page
